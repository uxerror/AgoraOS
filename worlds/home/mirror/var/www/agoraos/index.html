AgoraOS
A free Unix-like system for desktops, servers and routers

Getting AgoraOS

Boot the install CD and answer a few questions. The installer puts a desktop, a server or a router system on your disk.

Packages

Everything in AgoraOS comes in packages, kept in our archive:

  • HTTP: http://ftp.agoraos.org/agora/
  • FTP: ftp://ftp.agoraos.org/agora/ (anonymous)

Your system finds it through /etc/apkg/sources.list:

apkg http://ftp.agoraos.org/agora stable main

Then, as root:

apkg update
apkg search irc
apkg install apache2

Mirrors

Use a mirror near you, it is faster for you and kinder to us:

  • mirror.lanlink.net - LanLink Internet

Each package's size and MD5 sum are in the index, and apkg checks them. The index itself is only as trustworthy as the server you get it from.
