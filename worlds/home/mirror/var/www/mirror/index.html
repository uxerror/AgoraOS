LanLink Mirror

Free software archives, close to home for LanLink customers.

  • AgoraOS - a copy of ftp.agoraos.org, updated nightly

To use it, put this line in /etc/apkg/sources.list instead of the ftp.agoraos.org one, then run apkg update:

apkg http://mirror.lanlink.net/agora stable main

Problems? Write to mirror@lanlink.net.
